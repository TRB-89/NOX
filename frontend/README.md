# NØX — Frontend Interface (Module Preview & Design Foundations)

This directory is reserved for future frontend development (Module 3 - React Dashboard).
Module 1 initializes the design foundation and aesthetic guidelines for NØX.

## Aesthetic Foundations: Opium Industrial Cyberpunk

NØX adopts a disciplined, high-contrast, brutalist cybersecurity aesthetic inspired by minimalist industrial interfaces:

- **Primary Background**: `#080808` (Deep Abyssal Black)
- **Secondary / Card Background**: `#141414` (Matte Industrial Surface)
- **Chrome / Silver Accent Text**: `#D8D8D8` (High readability, metallic sheen)
- **Muted Metadata Text**: `#888888` (Timestamp, feature labels, secondary info)
- **Threat Alert Accent**: `#A62735` (Crimson alarm state, intrusion alert)
- **Safe / Normal Accent**: `#2D5A27` (Muted emerald safe indicator)
- **Grid / Border Accent**: `#222222` (Subtle boundary dividers)

## Planned Tech Stack (Future Modules)
- **Framework**: React 18+ / Vite
- **Styling**: Vanilla CSS / CSS Modules with custom design tokens
- **Visuals**: Canvas/SVG live traffic telemetry, neural prediction confidence gauges
